Autonomous Alertworks

自监督告警工坊

让系统先于人类发现问题：结合 LLM、时序数据与治理策略，构建可解释的自动告警链路，并以 Logbook 形式呈现。

  • Duration · 2024 Q1 - 2025 Q1
  • Role · Systems Researcher · LLM Ops
  • Stack · Azure Data Explorer · OpenTelemetry · Phi-3

研究摘要：设计 Alertworks Pipeline，将异常检测、LLM 解释与政策校验组合，输出可执行的告警故事。

交付物：Logbook 模板、可执行告警 DSL、以及现场演示的 story map。

Abstract

面对复杂系统，人工阈值不再可靠。Alertworks 用自监督任务训练 LLM 解释异常，并把证据映射到审计图。

  • 异常信号由 Prophet + STL 分解生成，提供初步候选。
  • LLM 解释引用 Telemetry Loop 的证据，自动生成决策摘要。

Methodology

  • Dual-Channel Alerts：将数值检测与语义检测并行运行。
  • Evidence Binding：每条告警附带数据切片、指标趋势、Policy 引用。
  • Action DSL：用 declarative 语言描述响应步骤，可直接触发 Runbook。

Experiment Setup

  • 数据：3 个 Copilot 产品、18 条关键指标、500+ 历史事故。
  • 对照：传统静态阈值体系。
  • 评价：Precision/Recall、解释评分、人类响应时间。

Results

  • 告警精准度 0.61 → 0.86；解释评分 4.2/5（由 SRE 评审）。
  • 平均响应时间从 42 分钟降至 11 分钟。
  • 运行 6 个月内，0 起重复事故未被捕捉。

Deliverables

  • Logbook 02 全套模板（Notion + Markdown + PDF）。
  • Alert DSL 编译器，可输出 Azure Automation Runbook。
  • 自监督训练脚本，支持离线再训练。

Next
